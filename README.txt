Bilim International School: прототип лендинга
=============================================

Как открыть: распакуйте архив и откройте index.html в браузере (нужен интернет:
GSAP 3.12.5, ScrollTrigger и Lenis 1.1.13 подключаются с CDN, шрифты с Google Fonts).

Устройство:
- Один файл index.html: вся вёрстка, CSS и JS внутри.
- photos/ содержит фото и логотип, а photos/t/ уменьшенные копии для ленты фото.
- Страницы переключаются без перезагрузки: блоки <div class="pg" data-page="...">,
  ссылки вида #about/#ossd открывают нужную страницу (функции goTo/showPage).
- Модальные окна: элементы с [data-open="id"] открывают dialog.dmodal.
- Анимации на GSAP + ScrollTrigger, плавный скролл на Lenis. Если включено
  prefers-reduced-motion, анимации отключаются.

Что ещё не готово:
- photos/price-list.jpg: прайс-лист пока не предоставлен (в окне «Прайс» заглушка).
- Отзывы учеников: пока заглушки.
- Форма заявки никуда не отправляет данные, нужно подключить бэкенд или WhatsApp/CRM.
